# guilhermehrcst.github.io

Personal site. Static HTML and CSS, no build step, no scripts, no third-party requests.

- `index.html`: English (default)
- `pt/index.html`: Português
- `assets/style.css`: shared styles (light and dark follow the system setting)

## Publish

1. Create a **public** repository named `guilhermehrcst.github.io`.
2. Push this folder to the `main` branch.
3. In the repository settings, open Pages and publish from `main`, root folder.
4. The site is then at `https://guilhermehrcst.github.io/` and `https://guilhermehrcst.github.io/pt/`.

To use your own domain later, add it under Pages settings. Do not use a pexiscale.com subdomain.

## Before publishing

There are no pending placeholders. The contact section (email, LinkedIn, Instagram, GitHub) is published on purpose. Remove any line you do not want public **before the first push**: once pushed, it stays in the history.

## Rules for this repository

It is public and its history is permanent. Never commit secrets, `.env` files, addresses, ID numbers, customer or store data, or code from private repositories. The contacts in the contact section are the only personal data meant to be public. Describe decisions in text instead.
